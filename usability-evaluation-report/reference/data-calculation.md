# 数据计算、脱敏与展示口径

## 输入契约与使用方式

先按实际问卷确认题号，不按列位置或题目名称模糊猜测。每个指标记录：metric_id、名称、来源文件/工作表与题号、题干、量表上下限、公式、有效 n、排除原因、缺失处理、未舍入值与展示值。题目含义不清时仅询问该映射，其余工作继续；不拿满意度题替代推荐意愿题。

运行 `python scripts/calculate_metrics.py input.json output.json`。输入为：

```json
{"scale_min":1,"scale_max":10,"overall_question":"Q1","dimension_questions":["Q2","Q3"],"nps_question":"Q4","responses":[{"user_id":"U01","Q1":8,"Q2":6,"Q3":10,"Q4":9}]}
```

overall_question/nps_question 可为空，dimension_questions 可为空列表；缺少对应题目则该指标为待补充，不臆造。输入 user_id 已通过身份对齐并脱敏，须唯一。重复提交先明确采用哪次回答，程序拒绝重复 ID。示例量表不可代替实际量表。NPS 始终使用独立的 0–10 整数评分；满意度量表按输入显式指定。同一维度集合必须同量表同方向；反向题按实际问卷规则转分并记录后再输入，不混入推荐题或背景题。

## 三种满意度

- 整体满意度（单题）：对应整体满意度题的有效分数总和 / 该题有效回答人数，作为主要指标。
- 各维度满意度：每道体验维度题分别对该题有效回答取平均；每个维度注明自己的 n，用于条形图/雷达图。
- 体验维度综合均分：可与前两者同时展示，明确标为补充。默认等权，默认排除整体满意度单题、NPS 题和非体验题。先求每位被试纳入维度题的均分，再对符合有效作答要求的被试等权平均。默认仅纳入维度题全部有效作答者；若研究方案要求其他缺失处理/权重，须显式记录并使用相应程序，不悄悄变更。

个人维度均分仅用于中间计算和附录匿名明细。正文呈现群体指标，不展示个人均分表。不同题有效 n 不同时，“先每人平均”和“直接汇总所有有效单元格平均”不一定相等，禁止混用。没有明确评分合成依据时不跨量表合成。

## NPS

仅使用推荐意愿题，0–10 整数：推荐者 9–10、中立者 7–8、贬损者 0–6。

NPS = (推荐者人数 - 贬损者人数) / 该题有效回答人数 × 100。

中立者计入分母；空值不计入分母，0 是有效评分。无有效回答显示未采集/待补充，不显示 0。输出推荐/中立/贬损人数和有效 n，结果范围 -100 到 100，作为分数显示，不加百分号。不从满意度推算，不把各任务 NPS 直接平均成总体 NPS。

## 缺失、精度与其他指标

空白/null/未作答排除并计数；非数字、布尔值、越界值单独登记为无效，不默默按 0 计算。访谈样本数不自动充当问卷或单题分母。均值内部保留精度，最后四舍五入到两位小数（含末尾零，如 8.00），不得先取整再平均。百分比与 NPS 展示也统一两位；人数/条目数保留整数。

完成率注明成功判定、成功人数和实际参与该任务的有效人数；接纳率注明接纳数及统计范围，未反馈不擅自当作拒绝。问题影响比例基于同任务可核验的参与范围；分母或人数冲突未核实时只显示原始人数和差异。上游原始字段与解析核对值分别保留，不覆盖原值。

## 默认脱敏

内部对齐后建立稳定 U01/U02 编号。已有用户1可映射 U01；跨表先核对身份，不能仅按各表行序分配，同名/冲突不擅自合并。原始编号与姓名映射仅留在输入侧。

所有交付物（卡片、正文、附录、匿名 JSON、HTML 隐藏数据、悬停提示、文件名、图片文字）检查姓名、账号标识、邮箱、电话、原始文件路径和其他身份信息。用户原声中的身份信息替换为 [姓名]/[公司] 等，注明“已脱敏，其余原文保留”，不润色或拼接原话。图片发现身份信息时脱敏后使用；无法可靠处理则保留占位说明，不直接放入原图。只替换元信息中的姓名不足以完成脱敏。

## 附录与验证

附录评分表：U 编号、逐题有效评分/缺失标记、整体满意度单题、个人维度均分、有效维度题数、综合指标纳入/排除原因。注明每个指标的题目映射、公式、有效 n 和来源。该表及随包数据均不得含真实姓名。

卡片、图表、正文、悬停值和衍生报告从同一匿名数据集读取，保留指标 ID。研究员更正需记录来源并重算；没有原始回答只能引用已有汇总并标“未复算”。交付前核对已知样例：NPS [10,9,8,6] = 25.00；均分 [8,9,9] = 8.67；[0,null,10] 的 NPS = 0.00、有效 n=2。验证缺失、越界、重复 ID 和零有效样本。
